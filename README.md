# Dashboard Screenshots

This folder contains screenshots of the four analytical pages
included in the World of Warcraft Raid Analytics Power BI dashboard.

## Raid Overview

The Raid Overview page provides a high-level view of raid and player
performance, including player damage comparisons, damage changes,
healing received, interrupts, and other encounter metrics.

![Raid Overview](Raid%20Overview.png)
## Boss Performance

The Boss Performance page focuses on encounter-level performance,
including attempts, kills, wipes, kill rate, fight duration,
average DPS, healing, and damage metrics.

![Boss Performance](Boss%20Performance.png)

## Player Performance

The Player Performance page provides detailed player-level analysis
across individual encounters, including fight results, active time,
damage, DPS, healing, deaths, interrupts, and dispels.

![Player Performance](Player%20Performance.png)

## Utility & Survivability

The Utility & Survivability page examines player survivability and
utility, including deaths, damage taken, healing received, interrupts,
dispels, and interrupt activity by ability.

![Utility and Survivability](Utility%20and%20Survivability.png)
